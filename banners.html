Home Promotions

Up to 10 banner placements, each independently controlled by its own enable / image_url / position Product Experience variables — not a fixed count of 5. Add more by configuring further slots on the dashboard, no redeploy needed (only raising the slot ceiling itself requires a code change — see the comment in the script).

Banner Order & Visibility

Each banner's own position variable decides where it lands (lower shows first); its enable variable decides whether it shows at all. Change either on the dashboard to reorder, add, or drop a banner — no single shared sequence variable to hand-edit.
